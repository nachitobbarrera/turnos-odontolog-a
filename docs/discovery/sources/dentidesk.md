# Dentidesk

- **URL**: https://dentidesk.com/
- **Fecha de investigación**: 2026-11-18

## Problema que resuelve

"El software que ordena tu clínica dental".

## Usuarios objetivo

Clínicas y odontólogos, centros médicos, instituciones educativas, sindicatos (Chile).

## Features detectadas

- Agenda personalizable, reprogramación, recordatorios internos, multisucursal
- Fichas clínicas y de especialidad (endodoncia, periodoncia, ortodoncia, etc.), odontograma con nomenclatura configurable
- Facturación SII (Chile), Alegra (RD), +20 reportes, stock
- Apps iOS/Android; agendamiento online como integración; WhatsApp automático "próximamente"
