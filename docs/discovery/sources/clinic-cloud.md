# Clinic Cloud

- **URL**: https://clinic-cloud.com/ (precios: /tarifas/)
- **Fecha de investigación**: 2026-11-18

## Problema que resuelve

"El software de gestión médica que necesita tu equipo".

## Usuarios objetivo

Clínicas y profesionales sanitarios (Doctoralia España SL — grupo Docplanner).

## Features detectadas

- Agenda multi-profesional y multisede
- Reserva online 24/7 vía Doctoralia; confirmaciones y recordatorios WhatsApp/SMS/email; IA telefónica "Noa Reception"
- Historia clínica, consentimientos con firma; odontograma solo en plan Max
- Caja, facturación (TicketBAI/Verifactu), mutuas, presupuestos, liquidaciones, stock, pagos online (Pro)
- IA clínica Noa Notes/Summary/Evidence; RGPD certificado; soporte humano 7 días, migración gratuita

## Pricing

EUR + IVA: Mini 29, Pro 49, Max 79/mes; Enterprise a convenir. Sin precios para Argentina.

## Posicionamiento

Todo conectado + visibilidad en Doctoralia.

## Diferenciadores

Integración nativa con el marketplace Doctoralia (que opera en Argentina).

## Notas del investigador

Referencia de UX y de modelo marketplace + software. Sin obras sociales ni ARCA.
