# Dentalink

- **URL**: https://www.softwaredentalink.com/ (ayuda AR: https://ayuda.softwaredentalink.com/es/collections/19196578-modulo-exclusivo-para-argentina)
- **Fecha de investigación**: 2026-11-18

## Problema que resuelve

"Haz crecer tu clínica dental con una gestión más inteligente".

## Usuarios objetivo

Consultas individuales y clínicas con varios profesionales y sucursales (Engenis SpA, Chile).

## Features detectadas

- Agenda online 24/7, agendamiento por WhatsApp, Contact Center IA, confirmación automática, reagendamiento automático (Titanium)
- Tareas automáticas de citas y controles (recall), email marketing, cobranza automática (Titanium)
- Historia clínica, odontograma, periodontograma, imágenes, análisis de RX con IA, presupuestos, planes de tratamiento, dictado por voz
- Caja, cobros presenciales y online, liquidación a profesionales, reportes, financiamiento a pacientes, convenios
- Firma electrónica, API (complemento), multisucursal (Pro)
- Módulo Argentina (títulos del centro de ayuda): obras sociales (alta, recaudación, conciliaciones) y receta electrónica
- ISO 27001, AWS cifrado, respaldos diarios, prácticas HIPAA
