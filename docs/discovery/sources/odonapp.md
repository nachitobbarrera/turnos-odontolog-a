# Odonapp

- **URL**: https://www.odonapp.com/
- **Fecha de investigación**: 2026-11-18

## Problema que resuelve

"Simplificamos la gestión" de círculos y asociaciones odontológicas: prestaciones, auditoría y liquidación.

## Usuarios objetivo

Instituciones odontológicas (círculos, asociaciones) y sus profesionales asociados.

## Features detectadas

- Todas las obras sociales en una pantalla con reglas ajustables
- Circuito de prestación Cargada → Auditada → Presentada → Liquidada; auditoría online según normas de cada OS
- Cuenta corriente única (prestaciones, débitos, materiales); facturación con validación ARCA; stock
- Módulo de eventos/cursos

## Posicionamiento

Plataforma institucional "Hecho en Argentina".

## Diferenciadores

Auditoría online + validación ARCA + acompañamiento del equipo fundador.

## Notas del investigador

No es un sistema de turnos: no evidencia agenda, turnos online ni ficha clínica completa. Relevante como posible integración/aliado (círculos). Clientes: Círculo Odontológico de Neuquén, Asociación Odontológica Marplatense, entre otros; "+750 odontólogos".
