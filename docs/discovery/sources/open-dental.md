# Open Dental

- **URL**: https://www.opendental.com/
- **Fecha de investigación**: 2026-11-18

## Problema que resuelve

"Quality Software for Dental Offices": software de gestión completo y personalizable a precio accesible.

## Usuarios objetivo

Consultorios dentales de cualquier tamaño (EE. UU.).

## Features detectadas

- eServices: Web Sched, Patient Portal, Integrated Texting, Automated Messaging, Payment Portal, Message-to-Pay, Web Forms, eClipboard
- Odontograma gráfico 3D; bloqueos; recall
- Claims con +20 clearinghouses; reportes y consultas propias
- Cientos de "bridges" a otros programas; conversiones desde +200 sistemas
- Foros de usuarios, webinars, documentación pública
